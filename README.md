### ~/ currently-building

#### Portfolio Simulation

A local-first portfolio research and simulation platform for exploring portfolio behavior under uncertainty.

- Multiple Monte Carlo engines, including geometric Brownian motion, Student-t, and jump-diffusion models
- Multi-asset covariance/correlation handling
- Interactive walk-forward analysis and deterministic replay
- Quantile fan charts, terminal-wealth distributions, and market visualizations
- Multi-tier caching across browser, Redis-compatible cache, and MongoDB-backed persistence
- React + TypeScript frontend with Cloudflare Workers deployment
- Explicit market-data provenance and security/publication checks

**Live external test deployment:**  
https://portfolio-simulation.portfolio-simulation-7k3m.workers.dev
